# The Aim

My Project is a large scale analysis, prediction and MLOps project.
The Project is my journey learning ML and Data Analytics as a whole.

# The Project Currenty

The Project initially will involve ML Models to predict *Severity*, which might seem odd at first glance; as why do we need to predict *Severity* if an accident has already occured.
The idea is not to predict how bad an accident is, rather given the geo-spacial, time and other data; how bad would an accident would be if one were to occur.
This helps categorize regions into high risk zones in accordance with Area and Time, helping potentially discover unidentified yet common accident patterns.

# The Vision

The Aim is to expand this further with Unsupervised ML to Novelty Detection for new patterns of accident,
Anomaly Detection for potential scam indications, and even more ML Approaches for a complete and self-coherent system of analysis.

# The Challenges

The Data is too Big and Noisy to work with all at once, so I need to use Traditional ML along side Incremental Learning.
Even high proficiency techniques like Ensemble Learning, Deep Learning, Swarm Intelligence, and much more need to be designed to work with Incremental Learning;
Hence you will see many of the Notebooks arranged as working with older notebooks and a lot of Custom Pipelines.
